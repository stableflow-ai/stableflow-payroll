# Table

Import from `@stableflow/pay-ui/table`. The component lives in the published package. Do not add a local copy under `src/components`.

```ts
import { Table, TableSkeletonRows } from "@stableflow/pay-ui/table";
```

Props and behavior are defined by `@stableflow/pay-ui`. `src/styles.css` must keep the Tailwind `@source` scan of the package `dist` folders, or the component classes are omitted from the build.
