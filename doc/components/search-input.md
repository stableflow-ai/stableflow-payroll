# SearchInput

Import from `@stableflow/pay-ui/search-input`. The component lives in the published package. Do not add a local copy under `src/components`.

```ts
import { SearchInput } from "@stableflow/pay-ui/search-input";
```

Props and behavior are defined by `@stableflow/pay-ui`. `src/styles.css` must keep the Tailwind `@source` scan of the package `dist` folders, or the component classes are omitted from the build.
